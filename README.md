# Keian Luxandor website

The Keian Luxandor fine jewellery website, built with React and Vite.

## Run it on your computer

```
npm install      # first time only
npm run dev      # editing mode: http://localhost:5173
```

## Check the real (fast) version

```
npm run build
npm run preview  # http://localhost:4173
```

## Where things are

- `src/data/home.js` – home page text and images
- `src/data/navigation.js` – top menu
- `src/data/footer.js` – footer links
- `src/config/site.js` – brand name, phone, email, social links
- `src/styles/variables.css` – colours and fonts
- `src/components/home/` – home page sections
- `public/` – images (use `.webp` for photos), `llms.txt`
